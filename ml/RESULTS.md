# Neural vs n-gram name models — results

Generated by `npm run ml` (`ml/experiment.ts`). Fixed seeds: re-running gives the same numbers.

## Setup
- **Data:** every word list in the app (1035 unique lowercase words after cleaning) split once, at random with a fixed seed: **828 train / 104 validation / 103 test**. No word appears in more than one split.
- **Baseline:** interpolated n-gram (letter pairs → next letter, mixed with shorter contexts, add-k smoothing). Best on validation: weights 0.5 / 0.4 / 0.1, k = 0.05.
- **Neural:** MLP language model written from scratch (letter embeddings → tanh layer → softmax), hand-written backpropagation verified by a gradient check in `src/ml/charlm.test.ts`. 12,000 mini-batch steps per setting.
- **Metric:** perplexity per character on unseen words (lower is better; 27 = random guessing).

## Interpretation
- **Prediction:** on this small dataset the neural model does not predict unseen words reliably better than a well-tuned n-gram — the honest result is a tie.
- **Generation:** the neural model produces more usable names per attempt (69.7% vs 43.8% valid, a statistically clear difference). Its letter embeddings share what it learns between similar letters, which seems to help it avoid unpronounceable runs that the n-gram produces when it backs off to shorter contexts.
- **Overfitting:** bigger networks fit the training words far better than unseen ones (gap up to 11.5 perplexity points); weight decay and the smallest setting generalised best. More data, not a bigger model, is the fix.

## Failure analysis
- Rejected samples, n-gram: `e`, `mo`, `kerlgaormer`, `cia`, `rboinutaelyrit`, `(empty)`, `amn`, `og`
- Rejected samples, neural: `iva`, `cimlcxwyom`, `noi`, `tha`, `maz`, `non`, `varbounaanich`, `ruananyxqlisdy`
- Hardest test words, n-gram: dulcet, young, phoenix, compass, elysium
- Hardest test words, neural: phoenix, elysium, young, dulcet, glyph

## Limitations
- **Small data:** 1035 words, hand-written, mixing English words, Hindi words and Indian and international names. Neural models usually need far more data to clearly beat n-grams, so this is a fair small-data comparison, not a general claim.
- **Perplexity isn't quality.** A lower score means better prediction of real words, not necessarily names people like; the user study (`docs/user-study.md`) is what measures that.
- **Next step:** a larger, clearly licensed name dataset, then re-run this exact script.
